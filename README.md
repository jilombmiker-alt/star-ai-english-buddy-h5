# 星星 AI 英语伙伴 H5

独立本地 H5 体验页，不需要 GitHub 或线上发布。

## 启动

直接运行：

```bash
node server.mjs
```

打开：`http://127.0.0.1:4190`

## 已实现

- 云端 AI 流式回复；失败时明确切换本地课程引导。
- 第一个板块只承担中英文语音陪伴：点击开始语音录入、实时转写、点击“录入完毕”、修改确认后发送；文字输入折叠为麦克风不可用时的备用入口。
- 每条星星回复可点击重听；全站使用浏览器默认女生声音，双语内容固定先播放英文，再播放中文。
- 顶部“AI 模型中心”支持主模型 + 备用模型：选择厂商、具体模型、API 地址并录入各自 API Key；主模型失败时，只有明确启用且完成配置的备用模型才会接替。
- 已提供 OpenAI、DeepSeek、Anthropic Claude、Google Gemini、豆包/火山方舟、阿里云百炼/千问、MiniMax、腾讯云 TokenHub 和 OpenAI 兼容自定义接口；每家都有推荐模型并允许填写新模型 ID。
- 全产品只有一个 H5 页面和一个 URL；顶部“英语对话 / 学习计划 / 我的成长”在同一应用外壳内原位切换内容，任务也在该页面中完成。
- 学习计划大厅包含今日计划、今日任务、朗读故事、认识单词、情景演绎、今日挑战和章节关卡树；每个入口进入独立任务画面。
- 页面采用固定高度应用外壳：品牌栏和三个学习入口保持不动，只有中间内容区域响应鼠标滚轮或手指滑动，避免整页大幅上下漂移。
- 今日计划不允许手动勾完成；朗读按播完句子、单词按答题正确、情景演绎按真实回应自动判定。
- 朗读升级为“首次听音 → 看着读 → 句意选择 → 二次听音 → 带提示背诵”；背诵支持英语语音转写、确认后提交和无麦克风备用入口，缺少理解与最终尝试时后端不允许通过板块。
- 子任务完成后显示完成反馈，并自动返回今日任务目录；从普通地图进入的章节完成后自动返回关卡地图。
- 地图已恢复树状路径视觉，并把原版“萌芽之森”的颜色测验做成一条可玩的综合挑战分支。
- 对话记录保存在浏览器 `localStorage`，可由页面按钮清空。
- 六关学习地图按真实完成情况顺序解锁。
- 每日签到、知识点/板块/章节积分、防重复发放和顺序解锁。
- 家长模式、家长免测试开关、家庭奖品设置和面向家长的数据监控界面已从 H5 移除。
- 本地后端仍记录必要的学习事件，供开发验收使用，不在儿童页面展示。
- 今日/本周/本月学习报告：掌握与积分只记一次，总练习和重复练习分别统计。
- 右侧“万能推进键”只切换验收页面，不生成完成记录、不加积分；上线前删除 `LOCAL_TEST_CONTROL` 标记区和 `advanceDemo` 逻辑。

## AI 模型中心

打开页面顶部的模型设置按钮即可配置。密钥通过本机页面提交给本机 Node 服务，并写入：

- `data/model-config.json`（文件权限 0600）
- `data/` 已被 `.gitignore` 排除
- 浏览器查询配置时只返回 `hasKey: true/false`，永远不会返回密钥内容
- 对话记录、监控事件和错误信息不记录密钥

主模型与备用模型都需要独立 Key。点击“测试连接”会先保存当前配置，再向对应厂商发送一句极短的 `只回复 OK` 测试文本；这可能产生极少量 Token 费用。正式对话费用由所选厂商按其账户规则收取。

为了兼容旧启动方式，仍可用环境变量预设 DeepSeek：

```bash
DEEPSEEK_API_KEY="你的密钥" npm start
```

## 默认女生声音

不再要求购买豆包语音。页面使用当前浏览器/系统提供的默认女生声音：优先选择对应语言中的常见女声音色，英语使用英语女声、中文使用中文女声，并保持“英文一遍 → 中文一遍”的播放顺序。不同电脑和浏览器提供的系统音色可能略有差异。

## 测试与数据

```bash
npm test
```

本地成长状态写入 `data/state.json`，监控事件写入 `data/events.jsonl`；这两个文件已被 `.gitignore` 排除。监控字段与儿童隐私边界见 [DATA-MONITORING.md](./DATA-MONITORING.md)。

## 边界

- 浏览器语音识别依赖 Web Speech API 和麦克风权限。
- 原始录音不由页面保存或上传；只有孩子确认发送后的识别文字才交给 AI。
- 不应输入儿童真实姓名、学校、电话、住址或账号。
- 当前数据是单机单档案，尚未实现多儿童、云同步和备份。
- 原仓库的统一地图是 7 个等级、82 个节点，其中 L1“萌芽之森”有 20 个故事/奖励/挑战/Boss 节点。当前 H5 没有删除原源码；本轮只融合了一个可玩的挑战节点与树状表现，尚未把 82 个节点全部迁移为 H5 可玩内容。
